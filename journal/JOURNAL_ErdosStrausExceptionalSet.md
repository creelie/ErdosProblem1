Title: An explicit exponent for the exceptional set of the Erdős–Straus equation
Authors: Deep Bhattacharjee (corresponding; itsdeep@live.com, d.bhattacharjee@erl-forschung.de; ORCID 0000-0003-0466-750X) and Ushashi Bhattacharya (rai.bhattacharya.in@gmail.com; ORCID 0009-0002-2254-3914)
MSC2020: 11D68 (primary); 11N36, 11N35, 11N13
Keywords: Erdős–Straus conjecture, large sieve, exceptional set, Egyptian fractions

Cover letter points:
- Vaughan (1970) bounded the exceptional set of the Erdős–Straus equation by N exp(−c (log N)^{2/3}) with no value of c. For the primes in the exceptional set, Dahan's recent sieve (arXiv:2608.24035) gives c = 0.065, and c = 0.0943 with the constant of its sieve sum found by Liu. The paper proves the bound for the whole exceptional set with every c < c₀ = 9/(2^{8/3} π^{2/3}) = 0.6607…, about seven times the best previous explicit value.
- Theorem B shows that c₀ is the limit of the large sieve with the residue classes used, so the constant is determined for this method.
- The main new step is the distinctness of the classes from three regions of the factorisations of (p + 1)/4, with an explicit six-parameter description of the coincidences between two of them.
- The paper does not claim the Erdős–Straus conjecture.
